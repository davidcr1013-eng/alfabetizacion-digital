# Preguntas acordadas para las tres guías

Estas son las nueve preguntas compartidas por el equipo. Se conservan los enunciados, las opciones y las respuestas correctas acordadas. Se agregan explicaciones breves para la retroalimentación educativa.

## Guía 1. Uso básico del celular

### 1. ¿Para qué sirve la pantalla táctil de un celular?
- A. Para interactuar con el teléfono usando los dedos.
- B. Para cargar la batería.
- C. Para aumentar el volumen.

**Respuesta correcta: A.** La pantalla táctil permite controlar el celular tocando elementos, botones y aplicaciones con los dedos.

### 2. Si queremos llamar a un familiar, ¿qué debemos utilizar?
- A. La calculadora.
- B. La aplicación de llamadas.
- C. La cámara.

**Respuesta correcta: B.** La aplicación de llamadas permite marcar números y comunicarse por teléfono con otras personas.

### 3. ¿Qué debemos hacer cuando la batería del celular está baja?
- A. Apagar la pantalla para siempre.
- B. Golpear el celular.
- C. Conectarlo al cargador.

**Respuesta correcta: C.** Conectar el celular a un cargador compatible permite recuperar la energía de la batería.

## Guía 2. Internet y comunicación

### 4. ¿Para qué sirve un navegador de internet?
- A. Para buscar y visitar páginas web.
- B. Para lavar el celular.
- C. Para tomar fotografías.

**Respuesta correcta: A.** Un navegador permite acceder a páginas web y consultar información disponible en internet.

### 5. Si queremos enviar una foto por WhatsApp, ¿qué podemos hacer?
- A. Encender la linterna.
- B. Entrar al chat y seleccionar la opción para adjuntar una foto.
- C. Abrir la calculadora.

**Respuesta correcta: B.** La opción para adjuntar permite seleccionar una fotografía del celular y compartirla en la conversación.

### 6. ¿Qué necesitamos normalmente para conectarnos a una red Wi-Fi protegida?
- A. Una fotografía.
- B. Un número de teléfono.
- C. La contraseña de la red.

**Respuesta correcta: C.** Una red Wi-Fi protegida solicita su contraseña para permitir el acceso a las personas autorizadas.

## Guía 3. Seguridad digital

### 7. Si recibimos un mensaje de un desconocido que pide nuestra contraseña, ¿qué debemos hacer?
- A. Compartirla inmediatamente.
- B. No compartirla y verificar quién envía el mensaje.
- C. Publicarla en redes sociales.

**Respuesta correcta: B.** Las contraseñas son privadas. No deben compartirse y es importante verificar la identidad de quien solicita información.

### 8. ¿Cómo podemos crear una contraseña más segura?
- A. Usando una combinación difícil de adivinar.
- B. Utilizando solamente nuestro nombre.
- C. Escribiendo 123456.

**Respuesta correcta: A.** Una contraseña segura debe ser difícil de adivinar y no utilizar datos personales evidentes ni secuencias comunes.

### 9. Si recibimos un enlace sospechoso, ¿qué es lo más recomendable?
- A. Abrirlo rápidamente.
- B. Enviarlo a todos nuestros contactos.
- C. No abrirlo y verificar su procedencia.

**Respuesta correcta: C.** Un enlace sospechoso puede dirigir a páginas falsas o peligrosas. Es mejor no abrirlo y comprobar su origen.
